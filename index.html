# Design System: Felipe Haas - Corretor de Imóveis de Luxo ## 1. Identidade Visual **Paleta de Cores (Extraída da Referência):** - **Primária (Luxo):** #1A1A1A (Preto Carbono / Graphite) - Para backgrounds profundos e elegância. - **Secundária (Branding):** #FFFFFF (Branco Puro) - Para contraste e tipografia limpa. - **Acento (Sofisticação):** #A1A1AA (Cinza Zinco/Slate) - Para subtextos e detalhes de borda. - **CTA (Ação):** #FFFFFF (Com efeito hover invertido ou glow sutil) - Foco em contraste máximo. ## 2. Tipografia - **Títulos:** Sans-serif moderna (Inter/SF Pro) com pesos variando de `font-light` (elegância) a `font-bold` (autoridade). - **Corpo:** Sans-serif (Inter) para legibilidade máxima em dispositivos móveis. ## 3. Componentes Estratégicos - **Hero Section:** Impacto visual imediato com copy direta em PT-BR. - **Diferenciais:** Grid limpo com ícones minimalistas. - **Social Proof:** Avaliações 5 estrelas e selos de autoridade. - **CTA WhatsApp:** Botão flutuante e seções dedicadas com micro-interações. ## 4. Estilo de Interface - Glassmorphism sutil em cards. - Bordas arredondadas (rounded-2xl/3xl). - Sombras suaves (shadow-2xl) para profundidade. - Transições suaves (duration-300).
